# Security Policy

## Supported Versions

Sovereign Stack is a testing and baseline environment for components before they transition to PiSelfhosting. Only the latest main branch is evaluated for security fixes.

| Version | Supported          | Note                                |
| ------- | ------------------ | ----------------------------------- |
| Latest  | :white_check_mark: | Active development and testing baseline |
| Older   | :x:                | Please update to the latest state   |

## Reporting a Vulnerability

If you find a security issue within the Sovereign Stack configurations or baseline code, please report it privately to ensure the safety of downstream implementations.

Please contact us directly via email at security@piselfhosting.com (please specify "Sovereign Stack" in the subject line). 

Do not open a public issue or pull request for unresolved security flaws.

## Response Timeline

* **Initial response:** Within 72 hours.
* **Remediation:** Vulnerabilities validated in Sovereign Stack will be fixed directly in the act
